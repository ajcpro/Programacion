# Problemas: Tema 02

En estos problemas debes seguir el procedimiento aprendido en el tema 1: analizar el enunciado, identificar los datos de entrada y de salida, elaborar un algoritmo que resuelva el problema, implementarlo en Java y probar el programa con diferentes datos.

## 1. Ficha de alumno

Escribe un programa que solicite el nombre, primer apellido y ciclo formativo de un alumno.

El programa debe mostrar posteriormente los datos introducidos con un formato similar al siguiente:

```text
Nombre: Antonio
Apellido: García
Ciclo: DAM
```

El programa debe utilizar indicativos claros de petición de entrada y, una vez introducidos los datos, mostrar un resumen que permita comprobar que se han leído correctamente.

## 2. Datos de un producto

Escribe un programa que permita introducir los datos básicos de un producto de una tienda.

De cada producto se debe introducir:

* nombre;
* categoría;
* código;
* descripción.

Una vez introducidos los datos, el programa debe mostrar una ficha del producto utilizando la información proporcionada.

Utiliza identificadores significativos y procura que la presentación del resultado sea clara.

## 3. Registro de una asignatura

Escribe un programa que solicite los siguientes datos de una asignatura:

* nombre de la asignatura;
* curso;
* ciclo formativo;
* profesor;
* aula.

Una vez introducidos todos los datos, el programa debe mostrar una ficha de la asignatura.

El diseño debe separar claramente los datos de entrada de la presentación de los resultados.

## 4. Ficha de un equipo informático

Escribe un programa que permita registrar los datos básicos de un ordenador.

Se solicitarán:

* fabricante;
* modelo;
* sistema operativo;
* nombre asignado al equipo;
* usuario principal.

El programa debe mostrar finalmente una ficha completa del equipo.

Debes utilizar variables del tipo adecuado para cada dato y constantes con nombre cuando consideres que algún valor del programa sea realmente constante.

## 5. Presentación personalizada

Escribe un programa que solicite al usuario su nombre, localidad y profesión o estudios.

A partir de estos datos, el programa debe mostrar un texto de presentación semejante al siguiente:

```text
Hola, soy Antonio, vivo en Zaragoza y estudio DAM.
```

El texto debe construirse mediante concatenación de cadenas y los datos introducidos por el usuario.

Antes de comenzar a codificar, determina qué datos necesita el programa, cuáles serán sus resultados y qué variables serán necesarias para almacenarlos.

## 6. Registro de una matrícula

Escribe un programa que solicite los datos necesarios para realizar un registro sencillo de matrícula de un alumno.

Como mínimo, se solicitarán:

* nombre;
* apellidos;
* ciclo;
* curso;
* grupo.

Una vez introducidos los datos, el programa debe mostrar un documento resumen de la matrícula.

El programa debe utilizar indicativos de entrada adecuados y realizar una impresión del eco de los datos introducidos antes de mostrar el resumen definitivo.
